# КОНВЕРТЕР

Офлайн-приложение для телефона: **фото → текст → кратко для методички**.

1. **Фото в текст.** Распознавание с камеры или из галереи (русский и английский). Движок Tesseract и языковые данные лежат в приложении, интернет не нужен.
2. **Кратко для методички.** Сокращает текст по правилам, сохраняя смысл:
   - рост, повышение, увеличение, поднятие, «растёт», «повышенный» → ⬆️; снижение, понижение, уменьшение, падение, «снижается», «сниженный» → ⬇️ («рост 186 см» не трогается);
   - «с большой вероятностью», «скорее всего», «по всей видимости» → вероятно; «с малой вероятностью» → маловероятно;
   - убирает вводные слова: «следует отметить, что», «на самом деле», «по сути», «так называемый»…;
   - сокращает связки: «для того чтобы» → чтобы, «так как» → т.к., «то есть» → т.е., «может привести к» → может →, «более 30» → > 30, «примерно 15» → ≈ 15;
   - **Мои замены** — свой словарь «что = на что», хранится на телефоне.

Исходный распознанный текст не меняется: короткая версия появляется в отдельном поле.

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `app.js` | приложение |
| `shorten.js` | правила сокращения (добавлять новые — в список `RULES`) |
| `lib/`, `lang/` | движок распознавания и языковые данные (~14 МБ) |
| `sw.js` | кэш для работы без интернета; при изменении файлов увеличить `CACHE_NAME` |
| `manifest.webmanifest`, `icons/` | установка иконки на телефон |
| `robots.txt` | запрет индексации поисковиками |

## Публикация на Render (как «Нутри анализатор»)

New → **Static Site** → репозиторий `KONVERT` → Branch: ветка с кодом → Build Command: пусто → Publish Directory: `.` → Deploy. Репозиторий остаётся приватным, сайт закрыт от поисковиков.

## На телефон

Один раз открыть адрес с интернетом и дождаться «✅ Готово к работе без интернета».
iPhone: Safari → «Поделиться» → «На экран „Домой“». Android: Chrome → ⋮ → «Установить приложение».
